#Gestion des patients
Ce projet est une application web JEE basée sur Spring MVC, Thymeleaf et Spring Data JPA. L’objectif est de permettre la gestion des patients via une interface web simple. L’application offre les fonctionnalités suivantes :

Afficher la liste des patients

Pagination des résultats avec navigation entre pages

Recherche de patients par mot-clé

Suppression d’un patient via un bouton dédié
